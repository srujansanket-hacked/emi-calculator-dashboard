# EMI Calculator & Tracking System

## 📌 Description
This project is a Streamlit-based EMI calculator that helps users calculate loan EMI, visualize repayment schedules, and analyze interest vs principal.

---

## 🚀 Features
- EMI Calculation
- EMI Schedule Table
- Interest vs Principal Graph
- Remaining Balance Chart
- Payment Distribution Pie Chart
- Downloadable CSV Report
- Attractive UI with Background Video

---

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib

---

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run dashboard.py
